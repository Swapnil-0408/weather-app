# 🌤️ Weather App
A simple and responsive **Weather Forecast Web App** that shows real-time weather data for any city using the OpenWeather API.

## 🚀 Features
* 🔍 Search weather by city name
* 🌡️ Displays temperature in Celsius
* ☁️ Dynamic weather icons (Clear, Clouds, Rain, Snow, etc.)
* 💨 Wind speed information
* 💧 Humidity percentage
* ⚡ Smooth UI with glassmorphism & animated background
* ❌ Error screen for invalid city (404 handling)
## 🛠️ Technologies Used
* **HTML5**
* **CSS3** (Glassmorphism + Animations)
* **JavaScript (Vanilla JS)**
* **OpenWeather API**
