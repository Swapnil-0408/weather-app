# 🌦️ Weather App
A modern and responsive weather application built using **HTML, CSS, and JavaScript**. It provides real-time weather information, a 5-day forecast, and location-based weather using the OpenWeather API.
## 🚀 Live Demo
🔗 https://swapnil-0408.github.io/weather-app/

## ✨ Features
- 🔍 Search weather by city name
- 📍 Get weather using current location
- 🌡️ Real-time temperature and weather conditions
- 💧 Humidity information
- 💨 Wind speed
- 📅 5-Day Weather Forecast
- ⏳ Loading animation while fetching data
- ❌ Error handling for invalid city names
- 🎨 Modern glassmorphism UI
- 🌈 Animated gradient background
- 📱 Fully responsive design for mobile and desktop

## 🔑 API Setup
This project uses the **OpenWeather API**.
1. Create a free account.
2. Generate your API key.
3. Replace the API key inside `script.js`.
Example:
```javascript
const API_KEY = "YOUR_API_KEY";
```
